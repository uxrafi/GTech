# Optimization & Uncertainty in Learning - CS7641 Spring 2026

This repository contains code for the OL Report assignment. The experiments investigate randomized optimization, Adam ablations, and regularization on the Adult Income and Wine Quality datasets.

## Directory Structure
- `src/`: Python source files
- `data/`: Place the Adult and Wine dataset files here
- `outputs/figures/`: Generated plots will be saved here

## Requirements
Install dependencies with:

pip install -r requirements.txt


## Usage
Run each part separately:

python src/part1_ro.py
python src/part2_adam.py
python src/part3_regularization.py
python src/part4_composition.py


## Datasets
- Adult: `adult.csv` 
- Wine Quality: `wine.csv

Place them in the `data/` folder.
